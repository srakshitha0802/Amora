# AMORA.CO — CATALOG ASSET REPOSITORY

This directory contains verified product assets, photography, and mockups organized by product category.

## Directory Structure

```text
public/assets/catalog/
├── bookmarks/               # Bookmarks & Reading Accessories (Page Whisper, Velour Mark)
├── corporate-merchandise/   # Corporate Merchandise (Mugs, Sipper Bottles, Desk Mats, Mousepads)
├── photo-products/          # Film Strips, Spotify Polaroids, Photobooth Strips
├── polaroids/               # Matte and Glossy Polaroids (Packs of 5, 8, 16)
├── posters/                 # A4 & A3 Matte / Glossy Posters
└── stickers/                # Paper & Transparent die-cut stickers
```

## Guidelines for Product Imagery
- **Authenticity First**: Prioritize genuine studio product photographs taken in the Kalyan workshop.
- **Aspect Ratios**: 
  - Standard product cards: 4:3 or 1:1 square.
  - Polaroids: Authentic 1:1.2 vertical polaroid ratio.
  - Extended Mats: 16:9 or 8:3 panoramic.
- **Format**: Optimized WebP or progressive JPG (< 250 KB per image).
